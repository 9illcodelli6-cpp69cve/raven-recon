# RAVEN Recon — Desktop App

واجهة محلية لجمع وعرض بيانات النطاق ومراجعة الطلبات، مع Repeater وDecoder وACL وتحليل انعكاس XSS. الدرجات والتصنيفات تساعد المراجعة؛ لا تثبت ثغرة تلقائيًا.

**حالة 2026-09-29:** المصدر يتضمن إصلاحات المراجعة الدفاعية. نتائج البناء والاختبارات القديمة لا تثبت حالة هذا المصدر؛ راجع [قائمة الإصدار](RAVEN_RELEASE_CHECKLIST.md) و[تقرير الإصلاحات](docs/DEFENSIVE_AUDIT_2026-09-29.md) قبل اعتماد ملف تنفيذي سابق.

## التشغيل

- النسخة المبنية: افتح الملف التنفيذي المحدد في بيان البناء الحالي، وتحقق من بصمته. الاسم المعتاد `dist/RAVEN.exe`؛ تعديل المصدر لا يحدّث نسخة تعمل بالفعل. نافذة التطبيق تعتمد على بيئة WebView المناسبة، وتجربة Windows نظيف ما زالت مطلوبة.
- من المصدر بنافذة محلية: ثبّت متطلبات التطبيق من `requirements-app.txt`، ثم شغّل `python launch.py`.
- من المصدر في المتصفح: شغّل `python -m raven.api`، ثم افتح عنوان loopback المطبوع. المنفذ المعتاد 8765، وقد يتغير عند انشغاله.

ابدأ بمختبر محلي وبيانات وهمية. عند إنشاء مساحة عمل يكون النطاق الدقيق هو الافتراضي، والنطاق الفرعي الشامل اختيارًا صريحًا. الجمع المجدول يستخدم المصدر المدمج وطلبات HTTP؛ يتجاوز subfinder وgau لأن المجدول لا يضبط حركة أدوات خارجية.

## الضوابط وحدودها

- طلبات الهدف عبر API تخضع للنطاق وفحص العناوين وتثبيت IP والتحقق من TLS، ولا تتبع التحويلات تلقائيًا.
- Emergency Stop يغطي قبول طلبات API اليدوية والجمع المجدول داخل العملية نفسها. الطلب المقبول سابقًا قد ينتهي. CLI والعمليات المنفصلة لها إعداداتها وحدودها الخاصة.
- Cancel في Intruder يوقف الدورة قبل الطلب التالي من الواجهة؛ الطلب الحالي قد يكون منتظرًا في الخادم أو جارٍ، ولا يلغيه هذا الزر منفردًا.
- الهوية وUA محفوظان لكل مساحة. خيارات المتصفحات ملفات توافق تاريخية، وليست كشفًا للمتصفح المثبت أو إصداراته الحالية. لا تدوير تلقائي أو ضمان لتجاوز الحظر.
- تُسترجع المساحة المحفوظة عند التشغيل. الإعدادات التالفة تمنع الإرسال، وتعارض ملكية مجلد مساحة العمل يتطلب اسمًا مستقلًا؛ لا تُنقل البيانات أو تُدمج تلقائيًا.
- **تنفيذ JavaScript لتأكيد XSS معطّل.** المتاح تحليل الانعكاس والسياق فقط؛ انظر [XSS Lab](RAVEN_XSS_LAB.md).
- تنقيح تصدير ACL أفضل جهد فقط؛ قد تبقى بيانات حساسة داخل الردود أو الروابط.

## البناء

`RAVEN.spec` هو تعريف البناء المستخدم بواسطة `build.bat`. داخل بيئة البناء المسجلة:

```text
python -m PyInstaller RAVEN.spec --noconfirm --clean
```

تحقق من نجاح العملية ومن الملف الجديد نفسه، وسجّل التبعيات ومعرّف المصدر وتغييرات Git غير الملتزم بها وبصمة SHA-256. وجود ملف قديم في `dist` أو ظهور رسالة انتهاء لا يثبت نجاح بناء جديد.
