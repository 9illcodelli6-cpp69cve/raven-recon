# models/

Trained model files are **not** stored in this repository (they are large, generated
artifacts, and pickled models should never be loaded from an untrusted source).

- RAVEN's ML triage models and the experimental native model are trained locally — see
  `docs/history/` for the training notes.
- For an AI assistant, use Claude (Settings → Claude) or connect your own local model —
  see [`docs/LOCAL_AI.md`](../docs/LOCAL_AI.md).
