Claude (Anthropic API)
With a key saved, Claude Opus 5.5 answers AI Chat and runs the Agent page. The key is stored encrypted in RAVEN's data folder and is never shown again; usage is billed to your Anthropic account. Every target request or command the agent proposes still waits for your Approve.

RAVEN Native (first-party)
RAVEN's own from-scratch generative model. Runs fully local — no network, no Ollama. The current checkpoint is an experimental bootstrap: it memorizes its small training curriculum and is not a capable assistant yet. Honest status only.
Selecting a checkpoint loads it locally and routes chat through RAVEN's own inference. Weak/degenerate output is expected at this maturity — it is labeled honestly, never presented as capable.
Optional External Provider (third-party)
RAVEN ships no native generative model. Chat is only available if you opt into an optional third-party provider (Ollama). It is OFF by default, is never contacted unless enabled, and is not part of core RAVEN AI.
When off, RAVEN makes no connection to Ollama and chat reports "native generative model not available" honestly.
Only used when the optional provider is enabled. Leave empty to auto-select the first available Ollama model, or pin one (e.g. llama3.2:latest). Not a RAVEN model.
