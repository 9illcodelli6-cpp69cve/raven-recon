## شو بتعمل الأداة

| القسم | شو فيه |
|---|---|
| **النطاق ومساحات العمل** | مساحة عمل لكل برنامج: الدومينات المسموحة (وwildcards)، الاستثناءات، المنافذ. أي طلب بيطلع من الأداة بينفحص عليها، واللي برّا النطاق أو العناوين الداخلية بينحجب. |
| **الاستطلاع (Recon)** | دومينات فرعية من سجلات الشهادات (crt.sh)، فحص HTTP لكل المنافذ المسموحة، اكتشاف مسارات من الروابط وrobots.txt والـ sitemap وملفات JS، تتبّع التغييرات بين الجولات، وترتيب حسب أولوية المراجعة. |
| **مختبر الطلبات** | Repeater، Intruder (headers، body، كشف الشذوذ مقارنة بخط أساس)، Decoder، سجل HTTP. |
| **مختبرات** | مختبر صلاحيات الوصول (مقارنة حسابين على نفس المورد) ومختبر XSS (تحليل سياق الانعكاس بدون تنفيذ سكربت). |
| **النتائج والأدلة** | نتائج "مرشّحة" مع أدلة، مراجعة، وتصدير تقرير Markdown لمساحة العمل. |
| **الوكيل الذكي (AI Agent)** | Claude Opus 5.5 بيخطّط وبيشتغل بأدوات الأداة — **كل طلب للهدف وكل أمر بيستنى موافقتك**. بيستعمل playbooks للفحص (API، صلاحيات، استطلاع، مراجعة كود، تحليل الباتشات، LFI بـ PHP، فحص بالمتصفح). |
| **المحادثة والترمنال** | أسئلة، بايلودات، كود — ومن الترمنال بأمر `raven-sec`. |
| **الأمان** | زر إيقاف طوارئ، حدود صرف وسرعة، sandbox للأوامر بدون إنترنت على لينكس، مفتاح API مشفّر، وكل البيانات عندك محلياً. |

## التنزيل والتثبيت

### ويندوز

**الطريقة الأسهل — تطبيق جاهز:**
1. نزّل `RAVEN-Recon-windows-x64.zip` من [صفحة الإصدارات](https://github.com/mahmodaltory12-beep/raven-recon/releases/latest).
2. تحقّق منه (تحت)، فك الضغط، وشغّل `RAVEN.exe`.

**من المصدر** (بدك Python 3.11+ — أو `winget install -e --id Python.Python.3.12` — وGit)، بـ PowerShell:

</div>

```powershell
git clone https://github.com/mahmodaltory12-beep/raven-recon.git
cd raven-recon
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

<div dir="rtl">

بيعمل بيئة Python خاصة، وأيقونة بقائمة Start، وثلاث أوامر: `raven-recon` و`raven-recon-web` و`raven-sec`
(افتح ترمنال جديد بعدها). للإزالة: `.\install.ps1 -Uninstall` (بياناتك بتضل).

### كالي لينكس / ديبيان / أوبونتو

**تطبيق جاهز:**

</div>

```bash
# نزّل RAVEN-Recon-linux-x64.tar.gz و SHA256SUMS.txt من صفحة الإصدارات، بعدين:
sha256sum -c SHA256SUMS.txt --ignore-missing
tar -xzf RAVEN-Recon-linux-x64.tar.gz
sudo apt install -y gir1.2-webkit2-4.1 bubblewrap
./RAVEN/RAVEN
```

<div dir="rtl">

**من المصدر (الأفضل على كالي):**

</div>

```bash
git clone https://github.com/mahmodaltory12-beep/raven-recon.git
cd raven-recon
./install.sh
```

<div dir="rtl">

السكربت بيسألك قبل ما يشغّل `sudo apt install` للحزم اللازمة، بيعمل `.venv`، بيضيف **RAVEN Recon**
لقائمة التطبيقات، وبيحط أوامر `raven-recon` و`raven-sec` بـ `~/.local/bin`. للإزالة: `./install.sh --uninstall`.

### التحقق من التنزيل

النسخ الرسمية موجودة **بس** بصفحة الإصدارات بهالمستودع. كل إصدار فيه `SHA256SUMS.txt` وتوقيع
**build provenance** من GitHub بيثبت إن الملف انبنى من هالمستودع:

</div>

```bash
sha256sum -c SHA256SUMS.txt --ignore-missing
gh attestation verify RAVEN-Recon-linux-x64.tar.gz --repo mahmodaltory12-beep/raven-recon
```

<div dir="rtl">

أي نسخة من مكان تاني ("PRO"، "مكرّكة"، إعادة رفع) **مش رسمية وممكن تكون ملغّمة**.

## ثلاث طرق للتشغيل

| | ويندوز | كالي / لينكس |
|---|---|---|
| **تطبيق مستقل** (نافذة خاصة) | قائمة Start ← RAVEN Recon، أو `raven-recon` | قائمة التطبيقات ← RAVEN Recon، أو `raven-recon` |
| **ويب محلي** (بمتصفحك، على `127.0.0.1` بس) | `raven-recon-web` | `raven-recon --browser` |
| **الترمنال** | `raven-sec` | `raven-sec` |

الويب المحلي ما بيسمع إلا على جهازك، وكل طلب للـ API بده token خاص بالجلسة — يعني ما حدا على الشبكة بيقدر يوصله.

## الدليل خطوة بخطوة

1. **اعمل مساحة عمل:** القائمة الجانبية ← **Workspace** (أو من Recon Workbench ← قائمة المساحات ← new workspace).
   حط اسم البرنامج و**نفس النطاق اللي البرنامج بيسمح فيه بالضبط**: الدومينات (`*.example.com`)، الاستثناءات، المنافذ.
   خلّي "السماح بالعناوين الخاصة" مطفّى إلا إذا مختبرك الخاص.
2. **حط هويتك:** Workbench ← **Identity**: الـ User-Agent والـ header اللي البرنامج طالبه (مثلاً `X-HackerOne-Research: <اسمك>`).
3. **شغّل الجمع:** Workbench ← **Run collection** — دومينات فرعية، فحص المنافذ، واكتشاف المسارات. بتشوف التقدّم بالترمنال تحت، وبتقدر توقفه بأي وقت.
4. **راجع السطح:** **Surface** (الأهداف مرتبة حسب أولوية المراجعة)، **Endpoints**، **Graph**، **Changes** (الجديد من آخر جولة)، **Runs**.
   الرقم أولوية مراجعة، **مش** حكم بوجود ثغرة.
5. **افحص بإيدك:** **Repeater** للطلب، **Intruder** للـ fuzzing مع خط أساس، **Access-control lab** لمقارنة حسابين، **XSS lab** للانعكاس، **Decoder** للترميز. وكل شي بينحفظ بـ **HTTP history**.
6. **استعمل الوكيل (اختياري):** حط مفتاح Claude (تحت)، افتح **AI Agent**، اختار *Claude Opus 5.5*، واكتب المهمة
   (مثلاً: *"افحص /api/orders/{id} لثغرة IDOR بحسابيّ التجريبيين"*). اقرأ كل طلب أو أمر بيقترحه واضغط **Approve** أو **Deny**.
7. **سجّل وبلّغ:** الوكيل والمختبرات بيسجّلوا نتائج **مرشّحة**؛ راجعها بـ **Findings**، بعدين **Export workspace report**، واكتب تقريرك بإيدك.
8. **زر الطوارئ:** **Emergency Stop** بيوقف كل شي بلحظة؛ **Resume** بيرجّعه.

## الذكاء الاصطناعي

الأداة بتشتغل كاملة بدون ذكاء اصطناعي. للميزات الذكية اختار:

**Claude (المنصوح فيه — أفضل نتائج):** اعمل مفتاح من [console.anthropic.com](https://console.anthropic.com)
(وحط حد صرف شهري)، بعدين RAVEN ← **Settings ← Claude (Anthropic API)** ← الصق ← **Save & test**.
- المفتاح **مشفّر** بمجلد بياناتك وما بيرجع ينعرض، وما بيوصل لأي أمر بتشغّله الأداة.
- بيشتغل بـ **AI Chat** و**AI Agent** و`raven-sec`.
- كل مهمة للوكيل إلها **حد صرف** (افتراضي $3) و**حد أدوار** (40) — من Settings. التكلفة التقريبية بتبيّن جنب كل مهمة.
- الدفع لـ Anthropic من حسابك، ولازم تلتزم بسياسة الاستخدام عندهم.

**موديلك المحلي (مجاني وبدون إنترنت):** نزّل [Ollama](https://ollama.com)، وبعدين `ollama pull qwen2.5-coder:7b`
(أو أي موديل)، ومن **Settings ← Optional external provider (Ollama)** فعّله واكتب اسم الموديل.
بيشغّل **AI Chat**؛ الوكيل بده Claude. التفاصيل والموديل المحلي المتقدّم RAVEN-Sec: [`docs/LOCAL_AI.md`](docs/LOCAL_AI.md).

**الـ Skills (أدلة الفحص اللي بيحمّلها الوكيل):** `api-recon` · `api-security` · `recon-breadth` · `code-audit` ·
`patch-diff` · `php-lfi-rce` · `browser-testing` — موجودين بـ `raven/skills/`.

**الترمنال:** `raven-sec` (محادثة)، `raven-sec -q "سؤال"`، و`raven-sec agent "المهمة" --scope app.example.com`
(بيسألك y/N قبل كل خطوة).

## الأمان والخصوصية

- **النطاق:** كل طلب بينفحص (الرابط القانوني، الدومينات الدولية صح، تثبيت العنوان، حجب العناوين الداخلية، بدون تتبّع تحويلات).
- **موافقتك:** على كل طلب للهدف، وكل جمع، وكل أمر بيقترحه الوكيل — والموافقة مربوطة بنفس الإجراء اللي شفته.
- **Sandbox بدون إنترنت** (bubblewrap على لينكس) لأوامر الوكيل، وما بيشوف مجلد البيت.
- **إيقاف طوارئ**، حدود طلبات وسرعة لكل مساحة عمل، وحد صرف لكل مهمة ذكاء اصطناعي.
- **البيانات عندك:** `~/.local/share/raven-recon` (لينكس) أو `%LOCALAPPDATA%\RAVEN-Recon` (ويندوز). بدون telemetry.
- **ما فيها:** حجب خدمة، برمجيات خبيثة، تثبيت دائم على الهدف، تخفّي من الحمايات، أو تجريب كلمات سر بالجملة.

## حل المشاكل

| المشكلة | الحل |
|---|---|
| بيفتح بالمتصفح مش بنافذة خاصة (لينكس) | `sudo apt install gir1.2-webkit2-4.1 python3-gi` |
| الوكيل: "bubblewrap is not installed" | `sudo apt install bubblewrap` (لينكس بس؛ على ويندوز الوكيل ما بيشغّل أوامر) |
| مفتاح Claude مرفوض | اعمل مفتاح جديد، تأكد من الرصيد/حد الصرف، والصقه من جديد |
| مهمة الوكيل انتهت بـ `REFUSED` | نظام الأمان عند Anthropic رفض خطوة — وضّح سياق التفويض (البرنامج، النطاق) أو اعمل الخطوة بإيدك |
| كل شي محجوب | راجع نطاق مساحة العمل والمنافذ، وتأكد إن Emergency Stop مش شغّال |
| الأوامر مش موجودة | ضيف `~/.local/bin` (لينكس) أو `%LOCALAPPDATA%\RAVEN-Recon\bin` (ويندوز) للـ PATH وافتح ترمنال جديد |
